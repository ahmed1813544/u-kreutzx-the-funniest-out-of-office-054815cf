Entry for the make.fun bounty [The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf).

`main.py` is a stdlib-only Python program that writes a single funny
out-of-office auto-reply line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt` when the variable is unset).

Run it with:

```sh
python3 main.py
```
